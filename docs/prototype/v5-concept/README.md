# V5 概念 ·「璇玑 Armillary」(2026-10-15,V5.2 已定稿)

> **定稿声明(2026-10-16)**:本版(V5.2 群青双主题)为最终设计,此后视觉实现以本目录为准。V1–V3 历史设计稿已删除;DESIGN.md 仅保留仍有效的领域与规范决策(信息架构/分档/桌面规范)。

独立于 V3「星历志」的新设计方向:**从星图到仪器**。V3 是一张记录星辰的图版(editorial),V5 是一台测量愿望的仪器(instrumental):刻度、游标、珐琅底、群青读数。

**V5.2 变更**(应用户要求,移除全部金/黄系配色):主色改为**群青**(青金石色——古代星图颜料,名为青金、贵于金)。夜仪 #82A8EA(文字,7.9:1)/ #5F8CD6(图形);昼版 #2E509C(文字,6.8:1)/ #3E63B8(图形,5.1:1)。欧档量距条、印签、评级星盘、流星与角标同步换色;翠玉/朱砂/春青/紫晶/钢青语义不变。

**V5.2 审查轮**(设计总监级审美复审,六项全闭环):①评级星盘字母 A 精确落环轴(北斗作配重);②昼版装饰星符避让全部文字区;③"正常"档昼版改冷灰 #8C9298,与夜仪同温;④翠玉向蓝青偏移(#4FC4B0/#177068),与春青拉开 ~30° 色相,"必中"与"超欧"两种绿一眼可分;⑤保底带加仪器走线(hairline trace)桥接徽章与次级读数组,次级读数(距软保底/距硬保底/四星保底)从顶部小字升格为右下读数仪;⑥稀有行洗色独立 token,双版感知等权。

**V5.1 变更**(应用户反馈):
1. **双主题定稿**:页 A「夜仪」默认深色 + 页 B「昼版」浅色(AA 校准的铜版纸印本,同一台仪器、两种铭刻)。浅色不是深色反相:独立的釉色 token(琥珀/墨字/翠玉深釉),语义色全部按 ≥4.5:1 校准。
2. **欧非量距条**:时间线每行改为量距条编码——**条长 = 垫抽数,条色 = 欧非档,尖端菱形游标**,背景轨保留四档分段与界线刻度。比"标尺钉位置"更 preattentive(长短+颜色可并行感知),与保底仪同一语法:每一行都是保底仪的一次读数。
3. **档位印签**:欧非总账评级章下新增四枚印签(超欧 ×4 / 欧 ×5 / 正常 ×7 / 超非 ×3),一眼读出全部档位分布(参考竞品的 chips 行,以仪器印签语法重述)。
