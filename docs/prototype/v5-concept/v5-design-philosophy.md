# 设计哲学 · V5

## Armillary Precision ·「璇玑」

> 在璇玑玉衡,以齐七政。——《尚书·舜典》

**一、以仪测量,不以图示人。** 古人铸铜为环,环环相扣,以浑天之仪量度星辰的行度—— 不是描绘天空,而是*测量*天空。本哲学主张一切界面成为这样一件仪器:数据不是被"排版"出来的,而是被"读数"读出来的。每一个数字都坐在刻度上,每一个状态都是一次仪表读示,每一条分隔线都是机械加工的准线。观者与信息之间隔着一层仪器的秩序感:克制、精密、值得信赖。这是无数轮校准才换来的从容,是长期伏案打磨才会有的精度。

**二、珐琅与群青。** 底色是曜石般的深珐琅——近乎纯黑的蓝,冷静、致密、不反光;其上以錾刻的方式落色:发丝线勾勒的环与刻度、群青的读数与游标——青金石,古人研磨作星图之色,名为青金,贵于金。群青在这里不是装饰,而是*度量衡*——只有被测量的对象才配得上这层深蓝。彩釉各司其职:紫晶、钢青、朱砂、春青,以及一枚翠玉——许诺之色,如玉之约,言出必践。所有颜色都必须在底色上通过可读性的淬炼,浅薄的高饱和是这个体系里最粗俗的错误。

**三、刻度即修辞。** 这个体系里最重要的图形语汇是*刻度线*:细密、均匀、成组,以patient的重复积累出仪器的可信度。软保底区以斜纹阴影标注,如仪表盘上的警戒弧段;游标是一枚菱形的群青指针,尖端永远指向此刻;分档标尺像一枚分度盘,四段釉色各占其位。文字被压缩为三类铭文:錾刻体的衬线大数字(读数)、细体大写字母的技术标注(铭牌)、等宽字的流水编号(钢印)。除此之外的一切说明都交给图形本身。

**四、环为骨,星为魂。** 构图以同心环为骨架:环是仪器的可动部分,承担分组、聚焦与仪式感;环内可以藏一片星官——七个点,几条细线,认得的人自会认出,认不出的人只觉得那是一片安静的星空。空间布局遵循仪器图版的传统:主体悬浮于图版右侧,左侧是它的"出厂铭牌"——釉色表、刻度解剖、字排标本,以索引编号与发丝线井然陈列。每个元素都经过反复推敲,力线对齐、间距成律,如同一件真正被制造出来的精密物件。

**五、克制的仪式感。** 这个体系拒绝廉价的光晕、渐变横幅与卡片堆叠;它的仪式感来自*精度本身*——一条完美对齐的垂直轨,一排密度一致的刻度,一次恰到好处的群青落笔。它应该看起来像一位顶尖制仪师耗尽数月打造的作品:每一处圆角都经过计算,每一级灰阶都经过比对,每一个字重都经过取舍。它测量的是运气,但它的气质是确定——因为在不确定的命运面前,人们需要的正是这样一台沉默、精准、永不撒谎的仪器。

**六、昼版 · Daylight Proof。** 仪器属于夜晚,铭刻属于纸张。同一台仪器应当有两种铭刻:夜仪以曜石珐琅为底,群青为读;昼版以铜版纸为底,群青与墨字为记——不是把夜晚反转,而是重新烧制一套经得起日光审视的釉色,让每一笔都通过对比度的淬炼。读数的方式在任何时刻都不改变:量距条的长度与颜色先于文字被感知,数字在各自的垂直轨上等待被核对。仪器可以换底,刻度不许含糊。
