**对比度校准(为什么不是原值照搬)**:官方 Latte yellow #DF8E1D 对白底仅 2.6:1(官方风格指南中 yellow 定位为警告类强调色,非正文),直接当文字色会"浅得看不见"。处理:金色三阶——`--r5` 大号数字 #C67C0F(≥3:1)、`--r5-deep` 小号金字 #A1660C(≥4.5:1)、`--r5-glow` 保留官方原值用于装饰图形;Mocha 底上 yellow 12.9:1,三阶同值。

**官方参考**:风格指南确认 Latte 含紫色系(Mauve #8839EF / Lavender #7287FD),且惯例为"彩色底上配 base 色文字"——Mocha 的 mauve CTA 用 crust 字即由此来。

字体(ui-ux-pro-max Gaming 档推荐,继续沿用):Chakra Petch(数字/拉丁)+ Russo One(评级章字母)+ 系统黑体(中文);正式实现内置字体文件。焦点环 2px、`prefers-reduced-motion` 关闭动效。

## 3. 信息架构 V2(按用户关心优先级)

用户打开抽卡工具时关心的事,按频率与 urgency 排序:

1. **保底进度与大小保底状态**——「垫到哪了、还有几抽出金、下一金是不是必中」→ 页签正下方常驻**保底状态带**(大数字垫抽数 + 刻度进度条 + 软/硬保底标注 + 金色菱形火星 + 状态章 + 距硬保底 N 抽 + 四星保底)。
2. **按抽卡顺序的出货记录**——「祈愿时间线」:游戏物品列表式条目,一行一次五星出货,新的在前,与游戏内历史同序。行 = 菱形头像章(34px)+ **金色物品名**(5★ 惯例,命座/精炼标签随名)+ 次行日期与卡池(muted)+ **欧非标尺**(220px 四段色区:金=超欧 / 浅金=欧 / 灰=正常 / 红=超非,菱形标记钉在出货位置,武器池按 19/40/68/80 换算)+ 右侧结果区「◆超欧 | 8 | 抽 | [不歪]」。**对齐轨(美感修订)**:结果区是严格列网格——档位槽 46px(词右缘对齐)/ 数字列 42px(按个位对齐)/ 单位列 16px / 结果章 56px(居中),全表六条垂直轨;所有行统一 1px 透明边框盒,掉落卡仅换边框颜色,内容零偏移。**超欧/超非 = 稀有掉落卡**:金/红渐变洗底 + 同色描边圆角卡;列表头部计数徽章「超欧 n / 超非 n」;流水号与完整时间戳进悬停与右键。设计结论(六轮迭代):①游戏工具的列表沿用游戏物品列表的视觉语言(金名、菱章、掉落卡),管理系统式表头+列网格是丑的;②小尺寸芯片字不可读,档位用 ≥14px 彩色词;③每行信息做减法,查询键进悬停与右键;④欧非程度最直觉的编码是标尺上的位置——「先看位置,再读数字」;⑤**美感来自对齐轨**:同类的量必须落在同一条垂直线上,流动性 flex 布局是对齐的天敌。
3. **欧非总账**——右栏:评级章(Russo One 字母章)+ 评语 + 口径行 + 彩蛋 → 指标瓦片(总祈愿/五星/平均出货/平均出 UP/歪率)→ 高光时刻 2×2。
4. **记录完整与同步**——状态栏(记录数/覆盖起点/最近同步/全本地徽章);逐抽流水(含四星三星)收在底部抽屉,含 301/400 二级筛选与仅五星筛选。

单画面无路由;池页签:角色活动(301/400 合并)/武器活动/常驻/新手/集录/未收录兜底。

## 10. 桌面(C/S)适配规范(V2.1 新增)

原型评审条可切换平台与窗口宽度,三种形态均已核对。

**窗口**:默认 1200×800,最小 980×640,自由缩放;布局用 **CSS 容器查询**随窗口宽度自适应(≤1150 切单列、隐藏流水号列),不是浏览器视口断点——应用在 1280 显示器与 980 小窗下都是完整形态。

**标题栏**:自绘(`decorations: false`),整条为拖拽区(-webkit-app-region / Tauri drag);平台差异:
- Windows:窗口控件居右(最小化/最大化/关闭),关闭悬停红底 #E81123;同步进行中点关闭先确认;
- macOS:`titleBarStyle` 交通灯居左由系统绘制,布局为其预留左侧 80px;
- 平台差异同时驱动快捷键前缀显示(Ctrl / ⌘)与 mac-note 提示显隐。

**快捷键**:F5 同步 · Ctrl/⌘+L 流水 · Ctrl/⌘+, 设置 · Ctrl/⌘+V 粘贴链接(非输入框焦点时)· Esc 逐层关闭(右键菜单→下拉菜单→模态→抽屉)· 池页签左右方向键。按钮 tooltip 内注快捷键。

**原生集成**(M3 由 Rust 侧实现,原型仅示意):
- 剪贴板检测:打开「粘贴祈愿链接」时自动读剪贴板识别链接并回填;
- 系统文件对话框:CSV / 客户端日志 / 备份导入导出;
- 拖拽导入:日志/CSV 拖入窗口即进入导入预览;**必须保留按钮等价路径**(WCAG 2.2 拖拽替代,ui-ux-pro-max 检索确认);
- 记录行右键菜单:复制物品名 / 复制流水号 / 在流水中定位;
- 通知:应用内右下角轻提示,v1.x 可选接系统通知。

**设置**:窗口内模态(非页面),六节:外观(跟随系统/明/暗)、启动(自动同步开关)、游戏客户端目录(国服/国际服,自动探测+手动指定;macOS 显示「仅粘贴/文件导入」说明)、备份(导出/导入,64MB 上限)、清空数据(危险区,二次确认)、关于(版本+本地隐私声明)。

**其他**:细滚动条(悬停显形)替代浏览器默认;输入框有明确边框/底色交互样式;模态内控件保留 2px 焦点环(ui-ux-pro-max 检索:Focus States,High);暗色主题不复用浅色灰阶(双套语义令牌)。
